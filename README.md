## 🚀 Getting Started

### Prerequisites
- Git
- JavaScript Runtime Environment

### Installation

```bash
# Clone repository
git clone https://github.com/{self.username}/{name}.git
cd {name}
npm install
```

### Running the Application

```bash
npm start
# Or for development: npm run dev
```

## Configuration

Create a `.env` file based on `.env.example`:

| Variable | Description |
| --- | --- |
| `FRONTEND_URL` | Application configuration variable |
| `PORT` | Application configuration variable |
| `VITE_SUPABASE_ANON_KEY` | Application configuration variable |
| `VITE_SUPABASE_URL` | Application configuration variable |
